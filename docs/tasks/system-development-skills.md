# 系统软件开发 Skill 集合接入

`pennix-lifecycle` 在 `main` 增加默认关闭的 `pennix-system-devel-skills`，固定公开源码提交和归档 SHA-256。复用集合的成员暂存、归属、更新、卸载和锁，不配置新的宿主服务或运行依赖。

定向 `plan/apply --component pennix-system-devel-skills` 只接受已选择的固定文档型集合。安装前核对来源、归档、锁和事务，发现旧锁、未知归属或其它事务时拒绝。已经精确匹配时不重新获取归档。已开始或结果未知的步骤只从原生 `recover` 核对，不因重跑首装而重放。

集合操作测试用实际归档结构验证首装、固定目标更新、拒绝、恢复和卸载；替换的是下载入口，不是解包或集合切换。发行验收另对公开固定归档和实际构建产物运行。取消选择和显式卸载的区别见仓库说明。
